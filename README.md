# SwooSay Talk

Where to talk about [SwooSay](https://swoosay.com)'s pronunciations of Star Wars: Unlimited card names.

**Know where a name is said?** Start a discussion in [Add a Source](https://github.com/davegandy/swoosay-talk/discussions/categories/add-a-source): the card, the word, and where it's said (a show, film, game, audiobook, or an interview with the people who made it), with the time. We listen to every one, and a name heard in an official recording becomes Verified.

**Think we got one wrong?** Tell us in the same place, with where you heard it said differently.

You'll need a GitHub account to post.
